＃后台食用指南进阶篇_OBS的使用

___

OBS一般用于录制视频或者直播推流，因为其庞大的社区以及投屏功能，活动部选择OBS作为**放映背景的软件**。

___

＃＃快速开始

打开OBS，点击场景，你可以看到老登留下的一系列场景。选择任意场景或新建一个场景，在**输出界面**右键点击投屏，选择一个显示器，你就可以看到大屏显示着输出的画面。

___


＃＃日常使用

（以下文字来源于ds，我懒）
OBS（Open Broadcaster Software）的核心工作流可以概括为：创建场景 (Scene) -> 添加来源 (Source) -> 开始录制/直播。理解了这个流程，你就能用它完成绝大部分的录屏和直播任务。

＃＃＃⚙️ 第一步：安装与初始设置

· 下载安装：从官网 obsproject.com 下载对应系统版本，右键安装包“以管理员身份运行”可避免权限问题。
· 运行自动配置向导：首次启动通常会自动弹出。它会测试你的硬件，自动优化直播或录制的基础参数，建议新手直接跟着走一遍。之后也可在顶部菜单“工具”中再次运行。

＃＃＃🧱 第二步：理解核心概念——场景与来源

· 场景 (Scene)：一个“画面布局”。你可以创建多个场景，比如一个“全屏游戏”场景，一个“带摄像头讲解”场景，方便在不同画面布局间切换。
· 来源 (Source)：构成场景的具体元素。在场景中通过点击来源面板的 + 号来添加。

＃＃＃🖥️ 第三步：掌握常用“来源”类型

· 显示器采集 (Display Capture)：捕获整个屏幕，适合演示操作或录制不便窗口采集的内容。
· 窗口采集 (Window Capture)：捕获特定程序窗口（如浏览器、PPT）。注意：添加后需在弹窗的“窗口”下拉菜单中手动选择要捕获的程序。
· 游戏捕获 (Game Capture)：专门捕获游戏画面，性能通常最好。
· 视频捕获设备 (Video Capture Device)：添加摄像头、采集卡等设备。
· 其他常用来源：图像（添加Logo、背景图）、文本（添加文字）、媒体源（在直播或录制中播放本地视频）。

＃＃＃▶️ 第四步：开始录制或直播

· 录制视频：在右侧“控件”面板点击 “开始录制” 。完成后点击 “停止录制” 。默认视频保存在 C:/Users/用户名/Documents/OBS/Videos，也可在“设置->输出->录像”中修改。
· 开始直播：在“设置->流”中填入直播平台的“服务器”和“串流密钥”，然后点击 “开始直播” 。

＃＃＃🔊 第五步：音频设置与优化

· 混音器 (Audio Mixer)：在界面右下角，可分别调节“桌面音频”（系统声音）和“麦克风”的音量。
· 音频设置：点击“设置->音频”可更换默认设备。
· 添加滤镜：点击混音器中麦克风旁的齿轮图标，选择“滤镜”，可添加“噪声抑制”来消除背景杂音。

＃＃＃⚡ 第六步：常用设置与效率提升

· 设置录像格式：建议在“设置->输出->录像”中将格式改为 MP4，兼容性更好。或用 MKV 格式录制以防意外崩溃导致文件损坏。
· 使用快捷键：在“设置->热键”中设置快捷键，例如为“开始录制”和“停止录制”绑定全局热键（如 Ctrl+F10），实现盲操。
· 使用“场景集合”和“配置文件”：在顶部菜单“场景集合”和“配置文件”中可保存不同用途的布局和设置（如工作用、直播用），方便一键切换。
· 开启“工作室模式”：点击“控件”中的“工作室模式”，可在不中断观众的情况下，在右侧预览并编辑下一个场景，准备好后一键推送到左侧直播画面。

＃＃＃🐛 常见问题与排查

· 预览窗口黑屏：最常见原因是来源未正确捕获。请检查是否在来源属性中正确选择了要捕获的窗口或显示器。
· 窗口列表为空 (macOS)：需要在“系统偏好设置 -> 安全性与隐私 -> 屏幕录制”中，勾选允许OBS控制电脑。
· 窗口列表为空 (Windows笔记本)：可能是双显卡冲突。请在“NVIDIA控制面板”中，将OBS主程序（obs64.exe）设置为使用“高性能NVIDIA处理器”。
